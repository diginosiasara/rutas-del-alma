# ALMA — asistente de lectura

- `alma.js` / `alma.css`: botón con el avatar (assets/img/chat/), panel de chat, búsqueda en el libro, intenciones (resumen, ejercicios, personajes, por dónde empezar), mensaje de apoyo ante expresiones de autolesión y conexión opcional a Ollama o a un servidor compatible con OpenAI.
- `indice.js`: texto oficial dividido en fragmentos (generado a partir del manuscrito). Si cambia el texto, hay que regenerarlo.
- Atajo: Alt + Mayús + C. Se cierra con Esc o con el botón del avatar.
- Sin backend: todo se ejecuta en el navegador. Ver `modelos-ia/README.md`.
